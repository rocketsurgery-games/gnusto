Deferred idea (user-originated). Open-ended value args (LH login 'xyzzy'/'plugh', combination locks) are not enumerable from object scope. Near-term (266.5.1) approximates by harvesting literal constants from source. Fuller model: treat KNOWLEDGE as hidden state -- a value arg becomes an available action argument only once the player 'knows' it (produced in prior output, or foreknowledge like the LH doc-check copy-protection password). Makes the action space state-dependent and monotone-growing, and models info puzzles honestly for reachability. Revisit after the constant-pool approximation proves insufficient.
